# ニャント！

NyanNyanToilet

猫のシステムトイレのシーツ交換日を管理するWebアプリです。

## 目的

自宅で飼っている猫のトイレは、定期的にシーツを交換する必要があります。
しかし、休みが不定期なこともあり、「最後にいつ交換したのか」を忘れてしまうことがありました。
そこで、シーツを交換した日と次回の交換時期を簡単に確認できるアプリがあれば便利だと考え、このアプリを制作しました。
また、単に日数を管理するだけではなく、楽しく継続して使えるアプリにしたいと考えました。
そのため、アプリ内に猫を表示し、交換日からの日数に応じて背景や猫の表情が変化することで、視覚的にも交換時期が分かり、「そろそろ掃除しなくちゃ」と自然に感じられるような機能を目指しています。

## Version 1で実装済みの機能

- 交換日を記録
- 経過日数を表示
- 交換周期を7日・14日から選択
- 日数に応じて背景が変化
- シーツ交換ボタン
- データをブラウザに保存

## 今後追加したい機能

- 猫の種類変更
- 背景の着せ替え
- 通知
- ポイント機能
- 複数トイレ管理
