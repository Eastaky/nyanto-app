# ニャント！

NyanNyanToilet

猫のシステムトイレのシーツ交換日を管理するWebアプリです。

## 目的

家で飼っている猫のトイレ掃除をいつしたのか忘れることがあり、トイレの掃除周期が不定期になることが多かったため
自作でトイレ掃除の周期を管理できるアプリを作りたいと思い始めてみました。


## Version 1で実装予定

- 交換日を記録
- 経過日数を表示
- 交換周期を7日・14日から選択
- 日数に応じて背景が変化
- シーツ交換ボタン
- データをブラウザに保存

## 今後追加したい機能

- 猫の種類変更
- 背景の着せ替え
- 通知
- ポイント機能
- 複数トイレ管理
